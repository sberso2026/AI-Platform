# Engineering OS V1 Packaging Architecture

Status: Phase 14A · `EngineeringOSCommercialPackagingDefined = true`

## Decision

Reuse Platform Commerce. Do **not** invent another commerce system.

Engineering OS is the purchasable/installable **OS product** containing separately
entitled modules/capabilities.

## Suggested entitlement layers

| Layer | Examples |
| --- | --- |
| Engineering OS base | shell, nav, shared domains access, search shell, AI workspace entry |
| Module entitlements | PI, II, AI, PC, DT, Interop |
| Premium capabilities | advisory predictive, vision, advanced controls contributors |
| Tool execution | ETF tool invoke families |
| Commercial solver orchestration | execution-host admin/execute — **does not imply provider availability** |
| Workspace/user policies | seat/role scoped |

## Truthfulness

Do not market live ETABS/SPACE GASS execution unless independently certified.
Federation and orchestration entitlements remain distinct from solver license
ownership (client-owned).
