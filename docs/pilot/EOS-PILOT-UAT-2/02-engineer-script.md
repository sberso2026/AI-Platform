Host: https://eos-pilot.rtbea.com.au. Use a seated engineer account when one is provisioned. Until then, founder may run this path in engineer mode (do not use Users invite during this script).

1. Sign in (password Sign In). Confirm Command Centre.
2. Open **RTB-PILOT-1788193387962** or the founder’s UAT-2 project. Set the header project selector.
3. Create or open a risk, TQ, and action on that project. Reopen each list.
4. Open an asset if one exists; confirm the project context still matches.
5. Open a document if one exists; confirm it retrieves.
6. Ask Engineering AI one project-scoped question. Do not treat the answer as approval.
7. Open Reports for the selected project.
8. Note empty states in plain language. File issues with [04-issue-register.md](./04-issue-register.md).
9. Sign out.
