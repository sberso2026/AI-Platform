# Shared intelligence follow-up

Components reused by document QA:

- Query planner (Project Intelligence)
- Retrieval (Project Intelligence + Engineering Retrieval Service)
- Evidence assembly (E5)
- AI Director generation
- Claim verification (new, document Ask)
- Citation assembly (document-body retrieval + Ask UI)

Modules that must not inherit certification:

- Meeting intelligence
- Findings / knowledge reports
- Inspection Intelligence AI
- Asset Intelligence
- Digital Twin simulation/explainability
- Project Controls decision support

Required follow-up: a dedicated evaluation pack per module covering query understanding, evidence classes, unsupported-claim rate, and abstention.
