# Security & Assurance Implementation Roadmap

Status: Ready · `SecurityAssuranceImplementationRoadmapReady = true`  
Evidence-based from Phase 15A gap register. Sequence may adjust after review.

## Recommended sequence (not pre-committed phase numbers)

1. **Control + Evidence Foundation** — catalogue, evidence refs, assessment, exceptions, dimensional posture  
2. **Isolation Assurance** — centralized probes reusing RLS/IDOR/cert evidence  
3. **AI / Data Security Assurance** — classification & provider compliance assessments  
4. **Secure Compute Assurance** — host/tool/solver posture evidence  
5. **Compliance Intelligence** — framework mapping dashboards (still ≠ certification)  
6. **Customer Assurance** — Trust Center approved surfaces only  

## Explicit non-goals until later approval

- SIEM / EDR / SOC / SOAR
- Threat-intelligence database
- Second Policy Engine / IdP / Audit / AI Runtime
- Moving S08 Identity SSO ownership into Sec&A
- Claiming ISO/SOC2/E8 maturity
