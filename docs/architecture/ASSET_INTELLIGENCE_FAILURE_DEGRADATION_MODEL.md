# Asset Intelligence — Failure & Degradation Models

## Failure concepts (reserved)
Failure Mode, Mechanism, Cause, Effect, Consequence, Detection Method, Mitigation, Confidence, Evidence Refs.  
Future compatibility: FMEA/FMECA/RCM/RBI/fault trees/SHM/PdM — **not implemented in 10A**.

## Degradation (reserved)
Mechanism, rate, trend, confidence, thresholds, warning/critical levels, source, model version, evidence window, prediction horizon.  
Examples: corrosion, fatigue, wear, cracking, coating breakdown, vibration deterioration.  
No unsupported prediction claims.
