# Asset Intelligence — Failure Model

## Locked terminology

| Term | Definition |
|------|------------|
| **Failure Mode** | Observable or functional manner in which an asset fails to perform its required function. |
| **Failure Mechanism** | Physical, chemical, electrical, mechanical or other process producing damage or failure. |
| **Failure Cause** | Underlying initiating or contributing cause. Distinguishes suspected / contributing / confirmed / root. |
| **Failure Effect** | Local/system/functional/operational effect caused by the failure. |
| **Consequence** | Impact on safety, production, environment, cost, compliance or mission. Not a canonical Engineering Core risk record. |
| **Detection Method** | Method or evidence by which the failure mode/mechanism was identified. |
| **Mitigation** | Action or control capable of reducing likelihood, severity or consequence. |
