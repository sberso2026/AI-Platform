# Pattern Entry and Transitions

Flexible entry: Work Packages may begin at later stages when justified.  
Entry basis stores: entry stage, reason, inherited baseline, available information, missing prerequisites.

Pattern change after start is non-destructive (engineering associations preserved) and records override provenance.

`EOS_PATTERN_FUTURE_OBJECT_PREGENERATION=NO` — just-in-time; no pre-creation of future-stage objects.
