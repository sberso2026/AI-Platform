# Pattern Gate Model

Gates assemble evidence from canonical WP associations, Decisions, Reviews, Deliverables, and Intelligence-1 impact states.

Statuses: `GATE_REQUIREMENTS_SATISFIED` | `READY_FOR_REVIEW` | `NOT_READY` | `BLOCKED_BY_IMPACT`  
`approved` is always `false` from pattern evaluation — human approval is separate.

Brownfield gates: M0–M6 foundation.
