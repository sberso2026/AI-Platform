## Qualification states

`INTEGRATED_NOT_VALIDATED` → `VALIDATED_BOUNDED` → `QUALIFIED_BOUNDED` → `QUALIFIED`

Only `qualification_authority` may change state. Connector health must not.

## Job states

`CREATED` → `VALIDATING` → `READY` → `SUBMITTED` → `RUNNING` → `COMPLETED` / `FAILED` / `CANCELLED` / `TIMED_OUT`
