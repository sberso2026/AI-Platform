## Lifecycle

`DRAFT` → `ASSEMBLING` → `READY_FOR_REVIEW` → `ACCEPTED` / `SUPERSEDED`

Readiness evaluation ≠ acceptance. AI cannot accept. Accepted packages are immutable; project baseline is not rewritten.
