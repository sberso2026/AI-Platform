# Dynamic Affected Discipline Discovery (Intelligence-3)

`EOS_DYNAMIC_AFFECTED_DISCIPLINE_DISCOVERY=PASS`  
`EOS_INITIATING_DISCIPLINE_NOT_COMPLETE_DISCIPLINE_SET=PASS`  
`EOS_DISCIPLINE_DISCOVERY_REQUIRES_LIVE_LLM=NO`

Deterministic discovery from explicit assignments, information dependencies, interfaces, assets, impacts, and document metadata.  
Initiating discipline is never assumed to be the complete set.

Module: `eos3-dynamic-affected-discipline-discovery.ts`  
API: `/api/engineering/projects/[projectId]/disciplines`
