# EOS 3 — Decision & Assumption UI Data Contract

`EOS_APPROVED_DECISION_UI_DATA_CONTRACT=PASS`  
`EOS_APPROVED_ASSUMPTION_UI_DATA_CONTRACT=PASS`  
`EOS_DECISION_ASSUMPTION_ENGINEERING_LANGUAGE=PASS`

## Engineer-facing labels

Decisions · Assumptions · Evidence · Options · Rationale · Authority · Supporting Information · Used By · Affected Items

Avoid: decision node, lineage engine, inference edge, graph traversal state.

## Decision detail foundation

ID/title, question, WP, Asset/System, status, authority, options, evidence, assumptions, calculations, affected items, recommendation, rationale (if decided), history.

## Assumption contextual display

Example: `ASM-001 Equipment operating mass — 12 t — Pending vendor confirmation — Used by CALC-001 — Source: Preliminary vendor data`

Assumptions appear in context — not as a forced register-only UX.
