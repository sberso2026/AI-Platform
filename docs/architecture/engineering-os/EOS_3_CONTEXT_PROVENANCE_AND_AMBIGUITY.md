# Context Provenance and Ambiguity

Every derived dimension carries provenance: reason, source, confidence (`HIGH` / `MEDIUM` / `LOW`), precedence.

Ambiguity states:

- `UNAMBIGUOUS`
- `MULTIPLE_VALID_CONTEXTS`
- `INSUFFICIENT_CONTEXT`
- `CONFLICTING_CONTEXT`

Confirmation by exception only — e.g. when a Calculation links to two active Work Packages.
