# EOS 3 — Work Package Cockpit UI

Implements Domain 1 UI contract as the first bounded cockpit.

## Header

`{WP-ID} {Title}` with context: Project, Facility/Area, System, Primary Asset, Related Assets, Maturity, Status, Lead, Participating, Owner (owner ≠ approver).

## Tabs

Overview · Engineering Design · Inputs · Dependencies · Decisions · Deliverables · Reviews · Changes

## Overview priority

Needs attention · Next recommended action · Key information · Readiness/maturity · Dependencies · Decisions requiring attention

Canonical objects are referenced, not copied into UI-only state.
