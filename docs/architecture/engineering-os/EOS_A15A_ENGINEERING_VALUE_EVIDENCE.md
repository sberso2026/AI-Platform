# EOS-A15A Engineering Value Evidence

Do not convert hypotheses into commercial claims. Synthetic execution time is software evidence, not business-value proof.

## PROVEN IN DEMONSTRATOR

- One coherent Crusher Support workflow composes Concept → Option → Decision → FEED → Review → Change/Impact → Construction RFI → Commissioning → Handover without rebuilding context by hand.
- EOS preserved engineering provenance (Work Plan fingerprints, artifact SHA-256/size, template class, Digital Thread relations).
- EOS identified changed/stale context after a synthetic vendor load revision and after a late handover change.
- EOS turned missing Mechanical/Geotechnical information into WAITING_ON_OTHERS, then RECENTLY_READY / DO_NOW after acceptance.
- EOS turned a construction RFI into assembled context + DRAFT FOR ENGINEER REVIEW without issuing correspondence.
- Human engineering authority was preserved: no automatic option winner, no automatic impact confirmation, no automatic review approval, no autonomous RFI/handover issue.
- Company Official and EOS Default template resolution both worked. New artifacts used OBJECT_STORAGE.
- Multi-project My Engineering Day aggregated authorized projects without contaminating the unauthorized project.

## OBSERVED

- Workbench-first actions differ by lifecycle (FEED vs CONSTRUCTION).
- Deterministic Pre-Issue Review completes without semantic AI.
- Authorized object download is scoped; cross-project object keys are denied.
- Demonstrator server execution of generate/review/impact is sub-second to a few seconds on the certification workstation (not a customer SLA).

## NOT YET PROVEN

- Authenticated browser HITL / AAL2 session.
- Native Microsoft Office open of generated files.
- Hosted malware path and real returned-file round-trip.
- Dependency-policy readiness.
- Multi-hour soak / memory growth.
- Isolated full-cluster database disaster recovery (A14B was logical metadata restore).
- Real-project (non-synthetic) engineering data.
- Live connectors, real solver, EXAMPLE_ONLY calculation used for design acceptance.
