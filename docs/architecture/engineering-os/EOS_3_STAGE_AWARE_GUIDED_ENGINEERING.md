# Stage-Aware Guided Engineering

Doctrine: `SHOW_RELEVANT_NOW` · `CREATE_WHEN_NEEDED` · `PRESERVE_HISTORY` · `DO_NOT_PRECREATE_FUTURE_WORK`.

Consumes Pattern, Maturity, Cockpit, Context, Priority — does not duplicate them.
Guidance is derived; never a shadow source of engineering truth.
Does not grant authority, auto-approve, auto-decide, or auto-issue IFC.
