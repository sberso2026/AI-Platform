# EOS-D1E-EU-C7-R4-E1 deflection authority

This phase targeted two first-generation deflection families and then stopped. It does not calculate deflection.

The families were cracked/uncracked curvature interpolation, then the simplified span-to-effective-depth check. The search used the existing Joint Research Centre workshop, a Finnish national-portal training extract from the same 2008 lecture series, and one commercial training extract as corroboration only. A public page is not treated as authority by itself. Derivative restatements of the same clauses are not counted as independent benchmarks.

The curvature extracts name an interpolation between an uncracked deformation and a fully cracked deformation, a load-duration coefficient, and numerical integration of curvatures along a member. They do not give a complete uncracked-curvature expression, cracked-curvature expression, cracking-moment expression, shrinkage-curvature expression, station contract, integration scheme, convergence criterion, support contract, or span contract. The institutional extract's state labels disagree with its own interpolation line and with the commercial extract. That notation conflict stays unresolved. An effective-modulus statement appears only in the commercial extract, so it is not bound. Crack width is not used as a deflection formula. Explicit creep remains distinct from the nominal-curvature effective creep ratio.

The span-to-depth algebra is still absent. The earlier equation-label conflict is not repaired. That check stays unauthorized.

No method is selected. No deflection profile is created. No sign convention is declared. D1C still supplies elastic closed-form deflection for its own bounded beam cases. That mechanics path is not an Eurocode concrete deflection method and is not implemented here as a curvature integrator.

Eurocode deflection is formally deferred. Crack-width checking and the explicit creep/shrinkage input state remain in place. The next phase is C7 closeout. Another autonomous deflection evidence search is not the next step.

Calculated creep, calculated shrinkage, engineer validation, a national annex, and formal conformance remain open.
