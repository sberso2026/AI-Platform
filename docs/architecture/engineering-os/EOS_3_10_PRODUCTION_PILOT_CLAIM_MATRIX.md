## Pilot eligibility (criteria only; no enrollment)

1. Explicit eos-3 entitlement (not inherited from eos-2)
2. Explicit EOS 3 enrollment after human GO in later phase
3. Internal/controlled tenant
4. Agreement to claim matrix + limitations register
5. No involuntary Production migration of EOS 2 projects
6. AI remains non-final
7. External solvers remain not globally qualified

## Bounded pilot scope

Enabled: canonical thread, knowledge, decision/optimization (human-gated), workflow/events, synthetic solver, non-authoritative AI, bounded project-to-asset, staging migration tooling.

Excluded: public signup, automatic migration, Production activation without EOS-3.11 human GO, global solver qualification, SPACE GASS execution certification, full EAM/CMMS.
