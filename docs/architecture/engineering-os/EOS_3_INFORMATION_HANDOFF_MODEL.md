# Information Handoff Model

A handoff is not merely Discipline A → Discipline B.  
It must identify the engineering information object being transferred.

Status path supports: IDENTIFIED → REQUESTED → … → AVAILABLE → ACCEPTED_FOR_USE → CLOSED.  
`AVAILABLE ≠ ACCEPTED_FOR_USE ≠ engineering approval`.  
Revision-aware history preserves prior accepted revisions when newer ones arrive.
