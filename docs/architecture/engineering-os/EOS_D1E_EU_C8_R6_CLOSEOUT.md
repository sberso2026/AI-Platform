# EOS-D1E-EU-C8-R6 closeout

This phase closes the bounded Eurocode concrete detailing track. It does not add a formula, a durability lookup, a design-anchorage method, a bond derivation, or a lap method.

The parent profile remains `EU-EN1992-1-1-GEN1-C8-DETAILING-REFERENCE`, generation `EN1992-1-1-GEN1`. Spacing and basic anchorage have their own reference sub-profiles. No lap profile exists. None of these profiles is a national annex. Formal conformance is not claimed. Engineer validation remains pending.

R1 bound the cover reference profile and left spacing, anchorage, and laps unbound. R2 implements and numerically validates cover assembly: the minimum cover is the greatest of an explicit bond-cover component, an explicit durability-cover component, and the profile absolute minimum, and the nominal cover adds an explicit deviation allowance. Exposure class does not calculate cover. Structural class and design life are not inferred. Provided cover is not a member compliance check.

R3 bound the minimum-clear-spacing reference. R3B implements and numerically validates that check for equal-diameter individual deformed bars, using surface-to-surface clearance, an explicit aggregate size, explicit nationally determined spacing coefficients, and the profile absolute minimum. Unequal diameters, bundles, mesh, tendons, and a project overlay stay out of scope.

R4 bound the basic required anchorage profile for one straight deformed bar in tension. R4B implements and numerically validates that length from the profile diameter divisor, an explicit design steel stress, and an explicit design bond strength. The result is not a design anchorage length. Design modifiers, minimum design anchorage, compression anchorage, hooks, and bends stay unimplemented. Bond strength and bond condition are not derived.

R5 recovered a design lap product that uses the basic required anchorage length, then found the shape, cover, transverse-reinforcement, and transverse-pressure factors named without expressions. The percentage factor and the minimum lap sit inside that incomplete product. No lap capability was selected. Lap runtime remains unimplemented. Another autonomous lap search is not scheduled. A later recovery is allowed only from materially new governed evidence.

The bounded track is complete for cover assembly, minimum clear spacing, and basic required anchorage. Complete Eurocode detailing is not. Full design anchorage is not. Laps are deferred. Maturity remains framework plus bounded methods. Product claim remains a mechanics reference capability.

The next concrete phase is member orchestration across the bounded C2 to C8 methods that already exist. Orchestration does not create a missing method. Deflection, calculated creep, calculated shrinkage, durability lookup, design anchorage, and laps stay outside that orchestration.
