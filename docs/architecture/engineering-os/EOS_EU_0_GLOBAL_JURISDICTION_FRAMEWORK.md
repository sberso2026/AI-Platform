# EOS-EU-0 Global Jurisdiction and Regulatory Architecture

Target: **global EOS architectural foundation**. Not EU market certification. Not country-by-country legal sign-off.

## Principle

EOS is **not an EU-only product**. Canonical stack:

1. Global core
2. Jurisdiction profile
3. Engineering standards profile
4. AI governance profile
5. Privacy / data profile
6. Security profile

EU AI, privacy, and cybersecurity requirements are a **high-water-mark profile** that deployments may select. They are not hard-coded into shared EOS domain logic.

`EU_MARKET_READY = NO`.

## Machine-readable contracts

- `@rtb/types` `global-governance.ts`
- `@rtb/engineering-os` `src/global-governance/`

No speculative database migration in this phase.

## Inventories

Horizontal modules and discipline gaps live in `EOS_HORIZONTAL_MODULE_INVENTORY` and `EOS_DISCIPLINE_GAP_REGISTER`. Generic Engineering OS features do **not** constitute completed Civil, Mechanical, Electrical, or other dedicated discipline packs. Structural remains **reference / partially implemented**.

## Compliance matrix

`EOS_GLOBAL_COMPLIANCE_MATRIX` marks architecture cells as `KNOWN`, `REQUIRES_LEGAL_REVIEW`, `REQUIRES_TECHNICAL_IMPLEMENTATION`, or `NOT_APPLICABLE`. It does not issue legal conclusions.

## Next

EOS-D0 Common Discipline Capability Framework must inherit this foundation. EOS-EU-D0 is the later high-water-mark review of that framework.
