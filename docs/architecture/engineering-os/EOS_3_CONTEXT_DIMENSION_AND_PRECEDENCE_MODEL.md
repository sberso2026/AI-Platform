# Context Dimension and Precedence Model

## Dimensions

Identity · Project · Work (WP / Pattern / Maturity) · Asset/System · Discipline roles · Stakeholder · Attention · Authority

Context remains multi-dimensional — never collapsed to a single string.

## Precedence (strong → weak)

1. Explicit opened object  
2. Explicit Work Package route  
3. Explicit Project route  
4. Active review / decision / change  
5. Canonical assignment  
6. Dependency / stakeholder obligation  
7. Recent valid working context  
8. Derived relevance  
9. Bounded suggestion  

Explicit route context is never replaced by higher-activity Work Packages.
Ambiguous equally plausible Work Packages are never auto-selected.
