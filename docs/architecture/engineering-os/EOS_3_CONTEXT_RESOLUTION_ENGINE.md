# EOS-3 Context Resolution Engine

Doctrine: **ENGINEERS_DO_NOT_MANAGE_CONTEXT_EOS_MANAGES_CONTEXT**

Context Resolution derives multi-dimensional engineering context from canonical EOS state (Project, Work Package, Asset/System, Pattern, Maturity, Dependencies, Disciplines, Impact, Decisions, Reviews, Changes, authority).

It is **not** a source of engineering truth. Snapshots are derived and reproducible.

Core resolution is deterministic and does not require a live LLM.
