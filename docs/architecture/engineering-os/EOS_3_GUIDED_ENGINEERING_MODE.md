# EOS 3 — Guided Engineering Mode

`EOS_DEFAULT_USER_MODE=GUIDED_ENGINEERING`

## Progressive disclosure

| Level | Name | Surfaces |
|-------|------|----------|
| 1 | Guided Engineering (default) | Objective, generated state review, tasks, next actions, simplified readiness, natural change |
| 2 | Engineering Workspace | Requirements, Basis, Assumptions, Systems, Calculations, Decisions, Changes, Deliverables, Reviews, Digital Thread |
| 3 | Governance Workspace | Gate evidence, audit, provenance, qualification, configuration, trust |

`EOS_ADVANCED_ENGINEERING_WORKSPACE_PRESERVED=YES`

## Task-based UX

Tasks include: define problem, review basis, review requirements, confirm mass, develop options, compare alternatives, resolve interface, assess change, review engineering, check G0 readiness.

## Next best action

Derived from canonical state (open assumptions, proposed requirements, interfaces, gaps). Recommendation ≠ authority.
