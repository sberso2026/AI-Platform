# Engineering OS — Shared Domain Ownership

**Phase:** 8I.1  
**assetOwnership:** `engineering_os_shared_domain`

## Authoritative shared domain (Engineering OS / Core)

Projects, assets, asset hierarchy, disciplines, packages, companies, people,
documents and revisions, equipment, locations, tags, and shared timeline
identities remain owned by the Engineering OS shared domain / Engineering Core.

## Module rules

| Consumer | Rule |
|----------|------|
| Project Intelligence | References canonical IDs; owns intelligence derivatives and feature lifecycle only |
| Future Inspection Intelligence | References canonical asset, project, workspace, document, location, user IDs |
| Knowledge Graph | Reference-only edges |
| Executive Dashboard | Aggregation-only |
| Engineering Reasoning Assistant | Orchestration-only |

Do **not** create Asset Intelligence in Phase 8I.1.  
Inspection Intelligence must **not** own canonical projects or assets.
