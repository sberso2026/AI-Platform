# Asset Intelligence — Criticality Model

Criticality is intelligence **about** assets — not identity ownership.

- Distinct from condition rating and health index
- Dimensional factors: safety, production, environmental, financial, operational, regulatory
- Governed review via Engineering Workflow SDK (`asset_intelligence.criticality_review`)
- Persisted in `asset_intelligence_criticality_states` (hosted Postgres)
- Canonical `assetId` remains Engineering OS Shared Domain
