# Inspection Intelligence — Extension Points

**Phase:** 9A · Reserved only · No implementation

## AI Vision (future compatibility)

Computer Vision, Object Detection, Segmentation, Crack Detection, Rust Detection, Corrosion Classification, Concrete Spalling, Leak Detection, Thermal Analysis, Missing Components, Protective Coating Analysis, Defect Classification, Predictive AI.

All inference must run through **Platform AI Runtime**. Results attach as observations / evidence / recommendations under human review.

## Knowledge Graph integration

Inspection Intelligence **contributes** nodes/relationships and timeline/evidence links to the **Platform Knowledge Graph**.

Forbidden: private graph, private embedding store, private AI runtime, private search engine.

Reuse Platform Knowledge Intelligence patterns established for Project Intelligence.

## Digital Twin compatibility

Observations become timeline events, asset events, inspection layers, condition history, and risk inputs **by reference**. II never duplicates Digital Twin ownership.

## Asset Intelligence compatibility

Asset Intelligence is **not** implemented. II references Engineering OS shared assets only. Future Asset Intelligence may consume inspection history for Asset Health, Risk, Hierarchy, Condition, Lifecycle — without II owning those domains.

## Taxonomy extensions

Custom classification namespaces allowed without forking core entities.
