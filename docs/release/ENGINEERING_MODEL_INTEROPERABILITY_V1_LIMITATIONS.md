# Engineering Model Interoperability V1.0 — Limitations

## Advisory intelligence

Mapping candidates and change-impact outputs are governed/advisory until human review. Imported external results remain `source_declared`.

## Forbidden engines / paths

- No silent CalculiX / SPACE GASS / ETABS / fixture substitution
- No live SPACE GASS or live ETABS claims in V1.0
- No full BIM viewer / full IFC semantic implementation / enterprise BIM throughput
- No analysis-model generation or source-model mutation

## Bounded IFC

Certified schemas: IFC2X3, IFC4, IFC4X3 via bounded STEP text extractor. Geometry/authoring remain out of scope.
