# Project Controls V1.0 — Limitations

## Advisory intelligence

Forecast, decision support, scenario, risk/opportunity, assurance, explainability and organizational learning surfaces are **advisory only**. They never approve contractual changes, execute schedule updates, post financial entries or mutate canonical project identity.

## Forbidden engines

CPM, earned value, resource leveling, schedule execution, financial posting and autonomous decision/learning/knowledge mutation remain closed in `version.ts`.

## Shared project domain

Project Controls consumes `ProjectReference` from the Engineering Shared Project Domain. It is not a project registry.

## Upgrade boundary

V1.0 closes over Phase 11M (`0.13.0-organizational-learning`). Upgrade certification verifies historical table readability after version bump to `1.0.0`.
